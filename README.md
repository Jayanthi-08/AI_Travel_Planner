# AI Travel Planner & AI Loan Eligibility System

Python assignment (Decision Making and Iteration Constructs) built with Streamlit.

## Applications

1. **AI Travel Planner** (`travel_planner.py`): collects trip details, validates input, classifies the budget, recommends a package by travel type, lists interests and a travel checklist, and calculates a Travel Readiness Score.
2. **AI Loan Eligibility System** (`loan_eligibility.py`): validates customer details, evaluates the credit score, assesses salary risk, lists submitted documents, and generates a final loan decision.

## Concepts used

Variables, user input widgets, lists, `if`, `if-else`, `if-elif-else`, `for` loops, input validation, business rule implementation, and a Streamlit user interface.

## How to run

```
pip install -r requirements.txt
streamlit run travel_planner.py
streamlit run loan_eligibility.py
```

The app opens in your browser at http://localhost:8501.
